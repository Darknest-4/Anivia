# Supabase e-mail sablonok (magyar)

Supabase → Authentication → Emails → Templates. A „Subject” mezőbe a tárgyat, a „Body” (Source) mezőbe a fájl tartalmát másold.

- `confirm_signup.html` — Tárgy: **Erősítsd meg az e-mail címed – ANIVIA**
- `reset_password.html` — Tárgy: **Új jelszó beállítása – ANIVIA**
- `change_email.html` — Tárgy: **Új e-mail cím megerősítése – ANIVIA**
- `magic_link.html` — Tárgy: **Bejelentkezési link – ANIVIA**
- `invite.html` — Tárgy: **Meghívtak az ANIVIA-ra**
